Central de Ajuda (Fictícia)

Como posso alugar um carro?

Navegue pela frota, escolha o seu modelo e preencha as informações do formulário de busca. Clique em "Buscar Veículos" e depois em "Reservar" no modelo desejado.

Quais os requisitos para aluguel?

Ter CNH válida dentro da validade (CNHs vencidas bloqueiam alugueis) e não ser inadimplente no sistema de testes.

Como funciona o sistema de fidelidade?

A cada devolução realizada com sucesso, o cliente ganha 100 pontos de fidelidade que se acumulam e garantem descontos automáticos de 5%, 10% ou 15% nas próximas diárias.

Política de Privacidade (Fictícia)

1. Tratamento de Dados de Simulação

Qualquer dado cadastrado (nome, CNH fictícia, etc.) é armazenado em uma fila in-memory RAM temporária no Render e é apagado automaticamente sempre que o servidor reinicia.

2. Sem Coleta de Dados Reais

Este sistema não recolhe nem envia dados pessoais reais a terceiros, não armazena cookies invasivos e não realiza rastreamento comercial.

3. Segurança

As conexões e testes de API utilizam os protocolos HTTPS nativos da Vercel e Render para fins de segurança no tráfego de dados simulados do portfólio.
